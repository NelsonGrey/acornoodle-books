# Support

- **Repository questions, bugs, or website problems:** open an issue using the templates in this repository.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not file a public issue.
- **Book, publishing, or business questions:** contact the repository owner, [@mnelson3](https://github.com/mnelson3), or use the contact page on the Acornoodle Books website.

Before asking, check the [README](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
